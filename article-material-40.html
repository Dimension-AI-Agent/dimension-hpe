企業 AI 與 Agent 實務 · AI 入門與概念

用 Agent 概念小測驗引導訪客理解工具、規劃與行動

最大的開放式 AI Hub - Hugging Face這份測驗主要用 6 題確認學習者是否掌握 AI Agent 的最基本概念，包括「什麼是 Agent」、「Agent 為什麼需要規劃」、「工具的作用」、「Actions 與 Tools 的差異」、「LLM 在 Agent 中扮演的角色」，以及「哪些實際案例可被視為 AI Agent」。

Q1：什麼是 AI Agent？

題目：以下哪一項最能描述 AI Agent？

A. 一種能夠進行推理、規劃，並使用工具與環境互動，以達成特定目標的 AI 模型。
B. 一種只處理靜態文字的系統，本身沒有任何能與周遭環境動態互動或執行實際操作的機制。
C. 一種僅限於回答問題的對話型 Agent，無法執行任何操作，也無法與外部系統互動。
D. 一個提供靜態內容的線上資訊庫，不具備執行任務或主動與使用者互動的能力。

Q2：規劃在 Agent 中扮演什麼角色？

題目：為什麼 Agent 在採取行動之前需要先進行規劃？

A. 主要是為了儲存或回想過去的互動，而不是規劃未來要採取的一系列行動。
B. 為了決定行動的先後順序，並選擇完成使用者需求所需的適當工具。
C. 為了執行一系列任意且彼此缺乏協調的行動，而不需要任何明確策略或目標。
D. 只是為了轉換或翻譯文字，不需要制定有目的的行動順序，也不需要進行策略性推理。

Q3：工具如何提升 Agent 的能力？

題目：為什麼工具對 Agent 很重要？

A. 工具沒有實際用途，也無法提升 Agent 執行基本文字生成以外操作的能力。
B. 工具純粹用來儲存記憶，無法協助執行任務或提升互動能力。
C. 工具會嚴重限制 Agent，使其只能生成文字，因而無法進行更多元的互動操作。
D. 工具能讓 Agent 執行純文字生成模型本身無法直接完成的操作，例如製作咖啡或生成圖片。

Q4：行動與工具有什麼不同？

題目：Actions（行動）和 Tools（工具）之間最主要的差異是什麼？

A. Actions 是 Agent 採取的步驟，而 Tools 則是 Agent 可以用來執行這些行動的外部資源。
B. Actions 和 Tools 是完全相同的元件，可以互換使用，兩者之間沒有明確差異。
C. Tools 是可用於各種功能的廣泛工具，而 Actions 則被認為只能用於實體世界中的互動。
D. Actions 必須由 LLM 來決定並執行，而 Tools 則是設計成完全不依賴 LLM、可自行運作。

Q5：大型語言模型在 Agent 中扮演什麼角色？

題目：LLM 如何協助 Agent 運作？

A. LLM 只是被動儲存資訊的資料庫，不具備主動處理輸入或產生動態回應的能力。
B. LLM 是 Agent 負責推理的「大腦」，透過處理文字輸入來理解指令並規劃行動。
C. LLM 被錯誤地認為只能用於影像處理，但實際上它的主要功能是處理與生成文字。
D. LLM 與 AI Agent 的運作完全無關，也就是說，在任何實際應用中都不需要使用 LLM。

Q6：以下哪一項最能展現 AI Agent？

題目：哪一個真實世界的例子最能說明 AI Agent 如何運作？

A. 網站上的靜態 FAQ 頁面，只提供固定資訊，不具備任何互動或動態回應能力。
B. 一個簡單的計算機，根據固定規則執行算術運算，不具備推理或規劃能力。
C. 像 Siri 或 Alexa 這樣的虛擬助理，能理解語音指令、進行推理，並執行設定提醒或傳送訊息等任務。
D. 電玩遊戲中依照固定腳本做出反應的 NPC，不具備推理、規劃或使用外部工具的能力。
