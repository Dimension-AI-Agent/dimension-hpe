企業 AI 與 Agent 實務 · AI 工具與開發框架

用 LangGraph 設計可保存狀態、恢復執行與人工介入的 Agent 流程

LangGraph 是支援長時間執行與狀態管理的 Agent 協調框架，可在流程中結合固定程式步驟與模型決策，並提供持久化及人工介入能力。這些機制適合用來說明企業流程如何保存進度、在必要步驟等待人員審核，以及在中斷後恢復執行。實際導入仍需設計資料存取、狀態儲存與故障處理，不能僅憑框架功能就視為完成企業整合。目前素材依據官方文件整理，尚未部署或實測。

LangGraph 概覽（已翻譯成中文）

使用 LangGraph 取得更高程度的控制能力，設計能可靠處理複雜任務的 Agent。

LangGraph 是一套低階的 Agent 編排框架與執行環境，用來建立、管理及部署長時間運作、具有狀態的 Agent。

它最大的特色之一，是能在同一張 Graph 中混合：

  • 確定性的程式邏輯
  • 由 LLM 驅動的 Agent 行為

因此開發者可以精確控制哪些流程必須固定、可預測且可稽核，哪些部分則交由模型彈性判斷。

LangGraph 本身主要專注在 Agent orchestration（Agent 編排）。如果剛開始接觸 Agent，官方建議先了解模型（Models）與工具（Tools）等基本元件。

LangGraph 可以搭配 LangChain 使用，但並不強制依賴 LangChain。

如果希望使用較高階、已經封裝好的 Agent 架構，可以使用 LangChain Agents；LangGraph 則主要負責底層能力，例如：

  • Durable Execution（持久化執行）
  • Streaming（串流）
  • Human-in-the-loop（人在迴圈）
  • Persistence（狀態持久化）

LangChain 產品之間的關係

  • Deep Agents：建立在 LangGraph 上的 Agent Harness，提供規劃、Subagents、檔案系統工具及 Context Management。
  • LangChain：Agent Framework，提供模型、工具及 Agent Loop 的抽象層與整合。
  • LangGraph：Agent Orchestration Runtime，負責持久化執行、Streaming、Human-in-the-loop 與 Persistence。
  • LangSmith：提供 Trace、Evaluation、Prompt 管理及部署功能的平台。
  • LangSmith Engine：分析 LangGraph Agent 的 Trace，偵測問題並提出修正方案。
  • LangSmith Fleet：No-code Agent Builder，可透過範本與整合建立例行自動化 Agent。

安裝

使用 pip：

pip install -U langgraph

或使用 uv：

uv add langgraph

接著可以建立一個簡單的 Hello World Graph：

from langgraph.graph import StateGraph, MessagesState, START, END

def mock_llm(state: MessagesState):
    return {"messages": [{"role": "ai", "content": "hello world"}]}

graph = StateGraph(MessagesState)
graph.add_node(mock_llm)
graph.add_edge(START, "mock_llm")
graph.add_edge("mock_llm", END)
graph = graph.compile()

graph.invoke({"messages": [{"role": "user", "content": "hi!"}]})

可以搭配 LangSmith 追蹤 Request、除錯 Agent 行為並評估輸出結果。

核心優勢

LangGraph 提供建構長時間執行、具有狀態的 Workflow 或 Agent 所需的底層基礎設施。

它不會替你抽象化 Prompt 或 Agent Architecture，而是提供以下核心能力：

混合確定性流程與 Agent 流程

可以在同一張 Graph 中，同時使用傳統程式邏輯與由 LLM 驅動的決策。

需要可靠性、可預測性的地方使用 Deterministic Steps；需要彈性判斷的地方則使用 Agentic Steps。

Persistence

Agent 即使執行失敗，也能保存目前狀態，之後從原本停止的位置繼續執行。

Human-in-the-loop

可以在 Agent 執行流程中的任意階段加入人工監督，檢查或修改 Agent State。

Comprehensive Memory

支援具有狀態的 Agent，包括：

  • 執行過程中的短期 Working Memory
  • 跨 Session 保存的 Long-term Memory

使用 LangSmith 進行除錯

可透過視覺化工具查看 Agent 執行路徑、State Transition，以及詳細的 Runtime Metrics。

Production-ready Deployment

提供適合正式環境的可擴充基礎設施，用來處理 Stateful、Long-running Workflow 的部署需求。

LangGraph 生態系

LangGraph 可以單獨使用，也可以與其他 LangChain 產品搭配。

LangSmith Observability

集中進行：

  • Request Tracing
  • Output Evaluation
  • Deployment Monitoring

可以先使用 LangGraph 在本地端 Prototype，再搭配 Observability 與 Evaluation 能力部署到 Production。

LangSmith Deployment

提供專門為 Long-running、Stateful Workflow 設計的 Agent 部署與擴充平台。

也能讓團隊：

  • 發現 Agent
  • 重複使用 Agent
  • 設定 Agent
  • 分享 Agent
  • 使用 Studio 進行視覺化 Prototype

LangChain

提供各種 Integration 與可組合元件，簡化 LLM Application 的開發。

LangChain 中的 Agent Abstraction 本身就是建立在 LangGraph 之上。

致謝

LangGraph 的設計受到 Pregel 與 Apache Beam 啟發，其公開 API 介面則參考了 NetworkX。

LangGraph 由 LangChain 的開發公司 LangChain Inc. 建立，但即使不使用 LangChain，也可以獨立使用 LangGraph。
