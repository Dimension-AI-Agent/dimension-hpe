# 訊達 × HPE 驗收網站

[開啟網站](https://dimension-ai-agent.github.io/dimension-hpe/)

訊達主導的 HPE 合作網站，包含訊達服務、訊達成功案例、訊達文章及聯絡資訊。

網站由 GitHub Pages 發布，來源為本儲存庫的 `main` 分支。首頁兩支原始影片保留於本儲存庫的 Release 附件，避免 GitHub 單檔大小限制。

## 2026-11-09 內容更新

- 移除合作方案入口，重新整理應用情境及案例。
- 文章區收錄既有網站 35 筆已核准內容，提供站內閱讀、主題篩選及搜尋。文章區即時讀取既有公開網站的資料，只顯示已核准內容；文章更新、新增或撤下後將自動反映。首頁、方案和案例頁不隨文章同步。
- 智慧維修 AI Agent 的實際導入狀態及對外公開範圍待確認；外部案例不視為訊達客戶實績。
- HPE 標誌、產品文案、影片與第三方圖文的使用權，及匿名案例客戶公開授權，仍須向相關權利人確認。
- PCAI 原附圖因 HPE 標誌與命名尚待確認，未包含在本站。

## 2026-11-11 服務與案例架構調整

- 將應用情境的需求與規劃說明整合至三個服務頁，舊入口轉至首頁服務區。
- 成功案例頁從既有公開內容即時載入已核准的訊達客戶與自身導入案例；服務頁顯示指定的相關案例，來源下架時不顯示。智慧維修素材 material-13 的實際導入狀態待確認，暫不放入成功案例頁。
- 既有文章同步、首頁影片和聯絡資訊維持原有機制。

## AI 導入指南

從四個導入階段了解企業需求、HPE 技術角色與訊達服務，並可分別閱讀各階段的 HPE 與訊達說明。指南中的工作情境為示意，文章與案例連結沿用公開網站資料。
